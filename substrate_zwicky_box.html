Morphological Box Builder — Substrate
How to use this Zwicky (morphological) box
  1. Add or edit dimensions on the left. Use the Include checkbox to temporarily exclude a dimension.
  2. Click options to restrict a dimension to a subset. Use Select all / Clear to toggle quickly.
  3. On the right, browse combinations. Use the search box, pagination, and rows/page to navigate.
  4. Use Random combo to sample the space. Copy any row; export CSV with an adjustable limit.
  5. Save/Load preset to JSON. Your current state is also saved to your browser automatically.
  6. If columns overflow, scroll horizontally in the combinations section.
